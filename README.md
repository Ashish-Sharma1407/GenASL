# 🤟 ASL-to-Speech: Real-Time Sign Language Translator

A real-time American Sign Language (ASL) recognition system that detects hand gestures via webcam, translates them into words and sentences, and speaks them aloud using text-to-speech. Built with **MediaPipe** for hand tracking and a **Random Forest classifier** trained on custom geometric features.

---

## ✨ Features

- **Real-time hand tracking** using MediaPipe Hands (21 landmarks per hand)
- **Custom-trained gesture recognition** covering 15 common ASL phrases (`my`, `name`, `is`, `hello`, `thanks`, etc.)
- **Enhanced geometric feature extraction** (83-dim) — inter-fingertip distances, tip-to-wrist distances, and finger-curl ratios — to reduce confusion between visually similar signs (e.g. "eat" vs "drink")
- **Gesture stabilization** with a rolling prediction buffer to avoid flickering/jittery predictions
- **Sentence builder** with basic grammar correction (e.g. "my name" → "my name is")
- **Text-to-speech output** via `pyttsx3`
- **Data augmentation pipeline** (×15 dataset expansion) simulating lighting variation, rotation, scale, and mirroring
- **External dataset support** — optionally bootstrap alphabet letters from the ASL-MNIST dataset via Hugging Face
- Auto-detects **Camo Studio** (phone-as-webcam) or falls back to the built-in camera

## 🧠 How It Works

1. **Hand Detection** — MediaPipe extracts 21 (x, y, z) landmarks per frame.
2. **Normalization** — Landmarks are translated so the wrist sits at the origin, then scaled so the maximum absolute coordinate is 1. This makes recognition invariant to hand position and distance from the camera.
3. **Feature Engineering** — The 63-dim normalized vector is expanded to 83 dimensions with geometric descriptors (fingertip distances, tip-to-wrist distances, finger curl) that are lighting-invariant and better separate similar signs.
4. **Classification** — A `RandomForestClassifier` (300 trees) predicts the sign, gated by a confidence threshold (0.75) to reject uncertain predictions.
5. **Stabilization** — A rolling buffer of recent predictions must agree before a gesture is considered "locked in," preventing single-frame misfires.
6. **Sentence Building** — Confirmed gestures are appended to a running sentence. After a pause (2s) or when the hand leaves the frame, light grammar rules clean up the phrase before it's spoken aloud.

## ⚙️ Setup

### 1. Clone and install dependencies

```bash
pip install -r requirements.txt
```

**Dependencies:** OpenCV, MediaPipe, TensorFlow, NumPy, scikit-learn, pyttsx3, gTTS, Pillow.

> Note: `asl_data.py` additionally requires `datasets` (Hugging Face) if you want to bootstrap alphabet letters from ASL-MNIST — install with `pip install datasets`.

### 2. Camera setup

The app auto-scans for a **Camo Studio** virtual camera (phone as webcam) and falls back to your built-in webcam if not found. No extra config needed — just make sure Camo Studio is running first if you intend to use it.

## 🚀 Usage

### Record your own training data

```bash
python data_recorder.py
```
- `SPACE` — save one sample · `a` — toggle auto-record (1 sample/sec) · `n` / `p` — next/previous sign · `d` — delete last sample · `q` — quit
- Record in **multiple lighting conditions** (dim + bright) for a more robust model.

### Augment your dataset

```bash
python augment_data.py                # generates ×15 samples via noise, rotation, scale, mirroring
python augment_data.py --preview      # see stats without saving
```

### Train the model

```bash
python train_model.py                 # train on original recorded data
python train_model.py --augmented     # train on augmented data (recommended)
```
This saves `custom_gesture_model.pkl` and a `confusion_matrix.png` for evaluating per-sign accuracy.

### Run the live translator

```bash
python main.py
```
**Controls:** `f` — flip camera · `s` — speak sentence now · `c` — clear sentence · `r` — reset stabilizer · `q` — quit

### Visualize normalization

```bash
python normalization_viz.py
```
Captures a hand pose and plots raw vs. normalized landmarks side by side for demonstration/research purposes.

## 🏗️ Model Details

| Aspect | Value |
|---|---|
| Classifier | Random Forest (300 estimators) |
| Input features | 83-dim (63 raw landmarks + 20 geometric features) |
| Vocabulary | 15 common ASL phrases (e.g. my, name, is, hello, thanks, love, please) |
| Confidence threshold | 0.75 |
| Stabilization | 8-frame rolling buffer, min. 4 detection frames |

---

## 📌 Notes & Limitations

- Recognition accuracy depends heavily on lighting consistency and the diversity of recorded training samples — recording in both bright and dim conditions is strongly recommended.
- `gesture_model.py`, `sentence_builder.py`, and `speech_output.py` contain earlier, rule-based / standalone versions of logic that has since been superseded by the integrated versions in `main.py`; they're kept for reference and experimentation.
